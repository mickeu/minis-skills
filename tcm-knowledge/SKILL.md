## 一、中医基础理论体系

### 1.1 阴阳学说

**阴阳基本概念**：阴阳是对自然界相互关联的某些事物或现象对立双方属性的概括。

| 属性 | 阳 | 阴 |
|------|------|------|
| 空间 | 上、外、左、南 | 下、内、右、北 |
| 时间 | 昼 | 夜 |
| 温度 | 热、温 | 寒、凉 |
| 亮度 | 明 | 暗 |
| 状态 | 动、升 | 静、降 |
| 功能 | 亢进、兴奋 | 抑制、衰退 |

**阴阳基本规律**：
- **对立制约**：阴阳相互斗争、相互制约
- **互根互用**：阴阳互为根本，相互依存
- **消长平衡**：阴阳此消彼长、动态平衡
- **相互转化**：物极必反，重阳必阴、重阴必阳

**阴阳在中医学中的应用**：
- 组织结构：脏为阴、腑为阳；背为阳、腹为阴
- 生理功能：气为阳、血为阴；功能为阳、物质为阴
- 病理变化：阳盛则热、阴盛则寒；阳虚则寒、阴虚则热
- 诊断治疗：热者寒之、寒者热之；阳病治阴、阴病治阳

### 1.2 五行学说

**五行**：木、火、土、金、水

**五行生克**：
- **相生**：木→火→土→金→水→木（依次相生，生我者为母，我生者为子）
- **相克**：木→土→水→火→金→木（依次相克，克我者所不胜，我克者所胜）

**五行乘侮**：
- **相乘**：相克太过（如木亢乘土）
- **相侮**：反克（如木亢侮金）

**五行归类表**：

| 五行 | 木 | 火 | 土 | 金 | 水 |
|------|------|------|------|------|------|
| 五脏 | 肝 | 心 | 脾 | 肺 | 肾 |
| 五腑 | 胆 | 小肠 | 胃 | 大肠 | 膀胱 |
| 五官 | 目 | 舌 | 口 | 鼻 | 耳 |
| 形体 | 筋 | 脉 | 肉 | 皮毛 | 骨 |
| 五志 | 怒 | 喜 | 思 | 悲 | 恐 |
| 五液 | 泪 | 汗 | 涎 | 涕 | 唾 |

| 五季 | 春 | 夏 | 长夏 | 秋 | 冬 |
| 五气 | 风 | 暑 | 湿 | 燥 | 寒 |
| 五化 | 生 | 长 | 化 | 收 | 藏 |

### 1.3 脏腑学说

#### 五脏（藏精气而不泻，满而不能实）

**心（君主之官）**：
- 主血脉：推动血液运行
- 主神志：主管精神意识思维活动
- 在体合脉，其华在面，开窍于舌
- 与小肠相表里

**肺（相傅之官）**：
- 主气司呼吸：主一身之气和呼吸之气
- 主宣发肃降：宣发卫气、肃降清气
- 通调水道：参与水液代谢（肺为水之上源）
- 朝百脉、主治节：辅助心脏调节全身
- 在体合皮，其华在毛，开窍于鼻
- 与大肠相表里

**脾（仓廪之官）**：
- 主运化：运化水谷精微和水湿
- 主升清：将精微物质上输心肺
- 主统血：统摄血液在脉中运行
- 在体合肉，主四肢，开窍于口，其华在唇
- 与胃相表里

**肝（将军之官）**：
- 主疏泄：调畅气机、情志、促进消化
- 主藏血：贮藏血液、调节血量
- 在体合筋，其华在爪，开窍于目
- 与胆相表里

**肾（作强之官）**：
- 藏精：主生长发育与生殖
- 主水：主持水液代谢
- 主纳气：摄纳肺吸入的清气
- 主骨生髓，其华在发，开窍于耳及二阴
- 与膀胱相表里

**心包络**：心之外围，保护心脏，代心受邪

#### 六腑（传化物而不藏，实而不能满）

**胆**：贮藏和排泄胆汁，主决断
**胃**：受纳腐熟水谷，主通降
**小肠**：受盛化物，泌别清浊
**大肠**：传化糟粕，主津
**膀胱**：贮存和排泄尿液
**三焦**：通行元气，运行水液（上焦如雾、中焦如沤、下焦如渎）

#### 奇恒之腑

脑、髓、骨、脉、胆、女子胞（形态似腑、功能似脏）

### 1.4 气血津液

**气**：
- **元气**：最根本之气，源于肾，推动生长发育
- **宗气**：积于胸中，走息道行呼吸，贯心脉行气血
- **营气**：行于脉中，化生血液，营养全身
- **卫气**：行于脉外，温养脏腑，护卫肌表

**气的功能**：推动、温煦、防御、固摄、气化

**血**：
- 生成：水谷精微 + 肾精 → 营气 + 津液 → 血
- 功能：濡养全身，藏神
- 运行：心主血脉、肝藏血、脾统血

**津液**：
- 津：清稀，布散体表皮肤肌肉，濡润
- 液：稠厚，灌注骨节脏腑脑髓，滋养

**气血关系**：气为血之帅（气能生血、行血、摄血），血为气之母（血能载气、养气）

### 1.6 病因病机

**外感病因**：
- **六淫**：风、寒、暑、湿、燥、火（热）
- 六淫致病特点：季节性、地域性、相兼性、转化性
  
**六淫各自特点**：
- **风**：阳邪，主动，善行数变，为百病之长
- **寒**：阴邪，凝滞收引，易伤阳气
- **暑**：阳邪，炎热升散，多挟湿
- **湿**：阴邪，重浊黏滞，阻遏气机
- **燥**：阳邪，干燥伤津，易伤肺
- **火（热）**：阳邪，炎上燔灼，耗气伤津，生风动血

**内伤病因**：
- **七情**：喜、怒、忧、思、悲、恐、惊
- 七情致病：怒伤肝、喜伤心、思伤脾、悲伤肺、恐伤肾
- **饮食不节**：饥饱失常、饮食不洁、饮食偏嗜
- **劳逸失度**：过劳（劳力、劳神、房劳）、过逸

**病机**：
- **正邪盛衰**：正虚邪实，正胜邪退
- **阴阳失调**：阴阳偏盛、偏衰、互损、格拒、亡失
- **气血失常**：气虚、气滞、气逆、气陷；血虚、血瘀、血热、出血
- **津液代谢失常**：津液不足、水湿停聚（痰饮、水肿）
- **内生五邪**：内风、内寒、内湿、内燥、内火

## 二、中医诊断学

### 2.1 四诊

**望诊**：
- **望神**：得神、少神、失神、假神
- **望面色**：青主风/寒/痛/瘀；赤主热；黄主湿/虚；白主虚/寒/失血；黑主肾虚/寒/瘀/水
- **望形态**：强弱胖瘦、动静姿态
- **望头面五官**：头、目（目睛五轮）、鼻、耳、口唇、齿龈、咽喉
- **望舌**：舌质（淡红/淡白/红绛/紫暗）、舌形（老嫩/胖瘦/裂纹/齿痕/芒刺）、舌态（强硬/痿软/颤动/歪斜/吐弄/短缩）、苔质（厚薄/润燥/腐腻/剥落）、苔色（白/黄/灰黑）
- **望络脉**（小儿指纹）：浮沉分表里、红紫辨寒热、淡滞定虚实、三关测轻重
- **望排出物**：痰涎、呕吐物、二便

**闻诊**：
- **听声音**：语声、呼吸、咳嗽、呕吐、呃逆、嗳气
- **嗅气味**：口气、汗气、痰涕、二便、经带、恶露

**问诊**（十问歌）：
> 一问寒热二问汗，三问头身四问便，
> 五问饮食六胸腹，七聋八渴俱当辨，
> 九问旧病十问因，再兼服药参机变，
> 妇人尤必问经期，迟速闭崩皆可见，
> 再添片语告儿科，天花麻疹全占验。

**切诊**：
- **脉诊**：寸口脉法（寸关尺、浮中沉）
- **28脉**：浮、沉、迟、数、虚、实、滑、涩、洪、细、弦、紧、濡、弱、微、缓、促、结、代、革、牢、散、芤、伏、动、疾、长、短
- **按诊**：按胸胁、按脘腹、按肌肤、按手足、按腧穴

### 2.2 八纲辨证

**八纲**：阴阳、表里、寒热、虚实

| 纲 | 辨证要点 |
|------|------|
| **表证** | 发热恶寒并见，脉浮，苔薄白 |
| **里证** | 但热不寒或但寒不热，脉不浮 |
| **寒证** | 恶寒喜暖，面色白，肢冷，舌淡苔白，脉迟 |
| **热证** | 发热喜凉，面赤，口渴，舌红苔黄，脉数 |
| **虚证** | 久病，精神萎靡，声低气短，隐痛喜按 |
| **实证** | 新病，声高气粗，剧痛拒按 |
| **阴证** | 里、寒、虚证的综合表现 |
| **阳证** | 表、热、实证的综合表现 |

### 2.3 其他辨证方法

- **脏腑辨证**：各脏腑寒热虚实辨证（最常用）
- **气血津液辨证**：气病/血病/津液病辨证
- **六经辨证**（伤寒论）：太阳、阳明、少阳、太阴、少阴、厥阴
- **卫气营血辨证**（温病）：卫分、气分、营分、血分
- **三焦辨证**（温病）：上焦、中焦、下焦

## 三、中药学

### 3.1 四气五味

### 3.6 中药配伍

- **相须**：性能相类似的药物合用增强疗效
- **相使**：主辅搭配，辅药增强主药疗效
- **相畏**：一种药物的毒性被另一种减轻
- **相杀**：一种药物减轻另一种药物的毒性
- **相恶**：一种药物削弱另一种药物的功效
- **相反**：合用产生毒性或副作用

**十八反**（配伍禁忌）：
> 本草明言十八反，半蒌贝蔹及攻乌，
> 藻戟遂芫俱战草，诸参辛芍叛藜芦。

### 3.8 十九畏详解

## 四、方剂学

### 4.1 方剂组成原则

**君臣佐使**：
- **君药**：针对主病或主证起主要治疗作用的药物
- **臣药**：辅助君药加强治疗，或治疗兼证
- **佐药**：佐助（加强君臣药效）、佐制（减除毒性）、反佐（引经报使）
- **使药**：调和药性（如甘草），引经药

### 4.2 常用方剂（按功效分类）

**解表剂**：
- 辛温解表：麻黄汤（麻黄、桂枝、杏仁、甘草）

## 九、使用说明

### 使用方式

在对话中提及中医相关问题，本技能自动触发并提供准确的中医药知识。

### 参考标准

本知识库依据以下权威来源编写：
- **全国高等中医药院校"十四五"规划教材**（45本，已内置）
- 《黄帝内经》（人民卫生出版社）
- 《伤寒论》（人民卫生出版社）
- 《金匮要略》（人民卫生出版社）
- 《神农本草经》
- 《温病条辨》
- 中华人民共和国药典（2020年版）
- 中华中医药学会标准

### 注意事项

1. 本知识库仅作为中医药知识参考，不构成医疗建议
2. 临床用药需在专业中医师指导下进行
3. 方剂剂量未列出，需根据具体病情辨证施治
4. 中药配伍禁忌（十八反、十九畏）需严格遵守
5. 有毒中药（如附子、乌头、马钱子等）需严格炮制并控制剂量
