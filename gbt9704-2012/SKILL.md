# GB/T 9704-2012 党政机关公文格式

## 适用范围
各级党政机关制发的公文；其他机关和单位可参照执行。现行版本 2012-07-01 实施，替代 1999 版。

## 核心参数速记
- **纸张**：A4（210×297mm）；版心 **156mm×225mm**
- **页边距**：上 37 / 下 35 / 左 28 / 右 26（mm，±1mm）
- **行字数**：每面 22 行，每行 28 字
- **字体**：标题 2号小标宋；正文 3号仿宋；一级标题 3号黑体；二级标题 3号楷体；三级 3号仿宋加粗；版记 4号仿宋；页码 4号半角宋体数字

## 三大板块要素
1. **版头**：份号（仅涉密）→ 密级和保密期限 → 紧急程度 → 发文机关标志（红头）→ 发文字号（+签发人，仅上行文）→ 红色分隔线
2. **主体**：标题 → 主送机关（顶格冒号结尾）→ 正文（首行缩进2字）→ 附件说明 → 发文机关署名、成文日期（右空四字）、印章 → 附注（圆括号）→ 附件
3. **版记**：粗线 → 抄送机关（4号，句号结尾）→ 细线 → 印发机关/印发日期 → 粗线

## 使用工具
技能自带 `scripts/gongwen.py`（标准库，无需额外依赖）：

```bash
# 生成示例公文
python3 /var/minis/skills/gbt9704-2012/scripts/gongwen.py make --demo \
  --out /var/minis/workspace/gongwen_demo.html

# 根据 JSON 配置生成公文页
python3 .../gongwen.py make --config 公文.json --out 公文.html

# 校验公文配置合规性
python3 .../gongwen.py check --config 公文.json
```

**JSON 配置字段**（均可选）：`份号`、`密级`、`紧急程度`、`发文机关标志`、`发文字号`、`签发人`、`标题`、`主送机关`、`正文`（字符串数组）、`发文机关署名`、`成文日期`、`附注`、`附件`、`抄送机关`、`印发机关`、`印发日期`、`页码起始`。

**正文标题分级自动识别**：`一、`→黑体、`（一）`→楷体、`1.`→仿宋加粗，脚本自动加对应 class。

生成的 HTML 用浏览器打开（或 `minis-open` 预览），打印选 A4、边距无，可导出 PDF。完整规范见 `references/格式规范全表.md`。

## 常见答疑要点
- **发文字号**：年份用六角括号〔〕，4位数字，如「国发〔2012〕1号」，同〔〕是六角括号不是方括号。
- **上行文 vs 平行文**：上行文须标注签发人，发文字号居左空一字；平行文/下行文发文字号居中。
- **印章**：单一机关行文，印章端正居中下压成文日期，成文日期右空四字；联合行文每行排两个机关名称。
- **页码**：版心下边缘之下，单页居右空一字、双页居左空一字，数字两侧加一字线；版记前空白页和版记页不编页码。
- **信函格式**：红色双线（上粗下细）作边界，不发红色分隔线；**命令（令）** 用「×××令」红头；**纪要** 标题为「××××会议纪要」，不加主送机关、不加印章。
