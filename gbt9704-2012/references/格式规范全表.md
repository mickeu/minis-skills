# GB/T 9704-2012《党政机关公文格式》规范全表

> 标准状态：现行。2012-06-29 发布，2012-07-01 实施，替代 GB/T 9704-1999。
> 配套文件：《党政机关公文处理工作条例》（中办发〔2012〕14号）。

## 一、范围与引用标准
- 适用范围：各级党政机关制发的公文；其他机关和单位可参照执行。
- 引用：GB/T 10538（胶版印刷纸）、GB/T 15834《标点符号用法》、GB/T 15835《出版物上数字用法》、GB 3100~3102（量和单位）。

## 二、用纸与版面

### 用纸技术指标
- 纸张：定量 60~80g/m² 的胶版印刷纸
- 白度 85%~90%，不透明度 ≥85%，pH 值 7.5~9.5

### 幅面与版面（核心参数表）
| 项目 | 规格 |
|---|---|
| 纸张 | A4，210mm×297mm |
| 上白边（天头） | 37mm±1mm |
| 下白边（地脚） | 35mm±1mm |
| 左白边（订口） | 28mm±1mm |
| 右白边（翻口） | 26mm±1mm |
| 版心 | 156mm×225mm |
| 每面行数 | 22 行 |
| 每行字数 | 28 字 |
| 正文用字 | 3号仿宋体 |

## 三、字体字号速查
| 用途 | 字体 | 字号 |
|---|---|---|
| 标题 | 小标宋体 | 2号 |
| 正文 | 仿宋体 | 3号 |
| 一级标题（一、） | 黑体 | 3号 |
| 二级标题（（一）） | 楷体 | 3号 |
| 三级/四级标题 | 仿宋体加粗 | 3号 |
| 份号/密级/紧急程度 | 黑体 | 3号 |
| 发文机关标志 | 小标宋体，红色 | 推荐 |
| 发文字号/签发人/正文 | 仿宋体 | 3号 |
| 抄送机关/印发机关/印发日期 | 仿宋体 | 4号 |
| 页码 | 半角宋体阿拉伯数字 | 4号 |

## 四、公文各要素编排规则

### 版头（份号 ～ 红色分隔线）
| 要素 | 编排要求 |
|---|---|
| 份号 | 6位3号阿拉伯数字，顶格版心左上角第一行；仅涉密公文标注 |
| 密级和保密期限 | 3号黑体，顶格第二行，如「★机密★1年」 |
| 紧急程度 | 3号黑体，顶格，如「特急」「加急」 |
| 发文机关标志（红头） | 小标宋体，红色，居中；上边缘至版心上边缘 35mm；联合行文可用简称，最后一个机关名称居首 |
| 发文字号 | 3号仿宋，居中，发文机关标志下空二行；年份用六角括号〔〕，如「国发〔2012〕1号」；上行文发文字号居左空一字，与最后一个签发人姓名同行 |
| 签发人 | 仅上行文标注；「签发人」3号仿宋，姓名3号楷体，右空一字；多个签发人同行 |
| 红色分隔线 | 与版心等宽，标于发文字号之下 4mm 处 |

版头各要素的位置关系（自上而下）：
1. 份号（如需）
2. 密级和保密期限（如需）
3. 紧急程度（如需）
4. 发文机关标志（红头）
5. 发文字号（+签发人）
6. 红色分隔线

### 主体（标题 ～ 附件）
| 要素 | 编排要求 |
|---|---|
| 标题 | 2号小标宋体，红色分隔线下空二行；一行或多行居中；回行词意完整、排列对称、长短适宜（梯形或菱形） |
| 主送机关 | 3号仿宋，标题下空一行，居左顶格，回行仍顶格，末尾加冒号 |
| 正文 | 3号仿宋，主送机关下一行，首行缩进2字；标题分级见字体表 |
| 附件说明 | 正文下空一行，左空二字标注；附件名称后不加标点；多个附件用阿拉伯数字标顺序号 |
| 发文机关署名、成文日期、印章 | 单一机关行文：成文日期右空四字，署名居中排日期之上，印章端正居中下压成文日期；联合行文各机关署名、日期排法按标准图样；加盖印章的公文成文日期右空四字，印章不得压住正文 |
| 附注 | 居左空二字加圆括号，编排在成文日期下一行，如「（此件公开发布）」 |
| 附件 | 版记前另面编排；「附件」及顺序号3号黑体顶格，附件标题居中编排在附件左上角第一行 |

### 版记（抄送机关 ～ 印发机关）
| 要素 | 编排要求 |
|---|---|
| 分隔线 | 首条、末条用粗线，中间用细线，均与版心等宽 |
| 抄送机关 | 4号仿宋，首条分隔线下，左空一字；「抄送」后标全角冒号，回行与冒号后首字对齐，最后一个机关后标句号 |
| 印发机关和印发日期 | 4号仿宋，末条分隔线上；印发机关左空一字，印发日期右空一字，如「2012年7月1日印发」 |

版记一般置于公文最后一面（偶数页），版记前有空白页的，空白页和版记页均不编排页码。

## 五、页码
- 4号半角宋体阿拉伯数字，版心下边缘之下，数字左右各放一条一字线（如 - 1 -）
- 单页码居右空一字，双页码居左空一字

## 六、横排表格
- 单页码表格表头在订口一边；双页码表头在切口一边

## 七、特定格式
1. **信函格式**：发文机关标志不加红色分隔线，用红色双线（上粗下细）作版心边界；发文字号顶格居右空一字。
2. **命令（令）格式**：发文机关标志用「×××令」红色标识，令号居中编排。
3. **纪要格式**：标题由「××××会议纪要」组成，不加主送机关、不加印章。

## 八、其他
- 计量单位、标点符号、数字用法分别按 GB 3100~3102、GB/T 15834、GB/T 15835 执行。
- 成文日期中的数字用阿拉伯数字，年月日标全，如「2012年7月1日」。
- 公文首页必须显示正文；联合行文时每行排两个机关名称。

## 版本沿革
- GB/T 9704 首版 1988；二版 1999；现行 2012 版。
- 2012 版与《党政机关公文处理工作条例》配套实施，主要变化：发文机关标志上边缘至版心上边缘由 25mm 改为 35mm；份号、密级、紧急程度编排调整；印发机关和印发日期改置于版记末条分隔线上等。
