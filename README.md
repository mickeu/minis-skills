# Minis Skills（个人技能库）

我的 Minis 技能集合，同步自本地技能库 `/var/minis/skills/`。每个目录为一个技能，结构遵循 OpenMinis 规范（SKILL.md 必需，references/ assets/ 可选）。

## 在 Minis 中安装技能

从本仓库复制对应技能目录到 Minis 技能库，或让助手从 GitHub 安装。
