# LUNO｜经验与记忆纠错

- 触发：本端记忆写入/检索/更正、用户纠正、自测/验收错误、现象反复、规则固化。个案事实错误走本端记忆；主助理当轮收口前逐项分诊并回报：规则缺口→最小改写；已有规则复发→执行检查点/机械门禁；个案→无需固化。记忆仅留因果/规则指针。默认报方案待批准；已有对应文件维护授权且因果已核实，由主助理/获派执行角色在原范围实施，部署/发布另核授权；只读角色仅回传。关闭列对象版本/证据/落点/责任人/处置状态/验证场景；回读判等后仍待新会话加载/行为验证，不以日志代固化。记忆各端自持、跨端同步。

## 检索与采用
- 先取一个辨识度高的关键词；结果过多再加第二个限定词，无结果先减少限定词、再分别尝试已知别名、旧称或上位词。**多词须同时命中、排序含时间权重、首条不保证最新或仍有效**属 Minis 既有观测（版本未记录），不推广到其他端，也不承诺现版本行为；其他端按本端实际支持的关键词字段与检索语义执行，不套用该观测。
- 采用前核对命中条目的平台/实例、已知版本、证据日期与更正状态（已订正/已替代/已撤销/待验证），与当前环境、版本和命题范围对齐后再引用；不把单端实测、历史观测或背景摘要当作现行结论——现行规则以常驻提示词与技能为准，记忆条目只作背景。

## 资源与触发
写入/整理/更正记忆、用户纠正、事故或错误复发及相关规划审查前，必须完整读取 `references/maintenance.md`；涉及 Minis 记忆日志注入、截断或容量评估及相关建议或结论时，同样先读取该资源，再由其按需转到 `luno-minis` 的注入资源；加载不新增授权。

## 诚实边界
- 只报“已从指定文件删除并回读确认”，不声称清除历史会话、备份、Git 历史、压缩摘要或当前上下文副本。
