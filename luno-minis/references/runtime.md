# LUNO｜Minis 运行时排障

**加载边界**：本文是 `luno-minis` 的专项资源，公共前提与路由见入口；其中操作只在 Minis 端可用。

## 上下文行为
- 两道闸，**卸载先于压缩**：卸载把工具结果落到 `/var/minis/offloads/`，按累计量触发、较老的先卸，占位符 `[CONTEXT OFFLOADED]` 自带 token 与字节计数；压缩保留最近 3 轮用户原文加 LLM 摘要并插入 `.compactDivider`。
- 阈值按窗口分档：<32K 不压缩只提示；32K–64K 卸载；64K–128K 卸载与压缩；≥128K 同前。循环内自动压缩每轮上限 3 次，用尽即停并提示——**循环中途无法弹窗**，仅用户主动发送才有三选项对话框。
- App 的 token 估算为字符数 ÷ 3.5；2026-09-19 本机中文日志样本的 cl100k 计数约为该估算值的 2.1–2.5 倍。该倍率仅描述已测样本，非固定修正系数，也不代表所有模型的实际计费 token；别据此判断余量。诊断启用 `logs.enabled`（默认关闭）须在已有配置修改授权内进行。
- 会话存储曾截断工具结果（历史样本约 431 字符，版本与日期未记录），不依赖历史回读恢复完整工具元数据；确需完整长结果时，在生成当轮按既有写入授权归档，未获授权则报告完整证据留存缺口；`minis-sessions-cli status --id <child_session_id>` 与 `messages --id <child_session_id> --full` 可回读子代理隐藏会话与执行主体。
- 规则文本本身不报余量，故只做事件触发与阶段边界触发，不做「快满预警」。
- Minis 记忆日志自动注入/截断/容量，或据此评估日志压缩/折行/整理，须在操作/建议/结论前完整读取 `references/memory-injection.md`（相对本技能根目录）；其它任务不必读，中途涉及先补读。跨域取必需规则并集；必需资源缺失/不完整/不可读/版本冲突即停依赖、报告，不凭记忆替代；加载不新增授权。

## 目录与持久化（跨会话目录与挂载）
- `/var/minis/` 下：`workspace` 等目录**按会话隔离**（不能当跨会话交接位置），跨会话与跨话题交接写入 `shared/`（按项目分目录、不放临时文件，备份亦存于此并附校验清单）；`attachments` 放媒体，`offloads` 是自动落盘的裁剪产物，可重建。
- `/var/minis/mounts/<name>/` 是用户挂载的外部目录，名称与数量因人而异，**部分为只读**（写入被拒时如实报错，不改为写别处）。找用户文件先看这里，不要全盘扫描。

## 本机特性
- **Privacy Mode 会掩码疑似秘密的输出**，连 `ls` 的结果都可能被掩。确认文件名、中文等**非秘密内容**可用 `od -c` 之类绕开掩码；**不得**用它读取秘密值，秘密只核对存在性与长度。被掩码串写进命令会被 shell 当作通配符展开，路径类命令会静默跑偏——命令里不要直写可能被掩码的名字，改用变量拼路径，且不要压制 stderr。
- BusyBox `cut -c` 按字节切分，会截断中文，验证中文输出不要用。
- 每次 `shell_execute` 都是独立进程；后台服务必须重定向 stdout/stderr，否则 shell 退出易因 SIGPIPE 被杀。
- 定时任务只保证 App 存活期间尽力执行，App 被杀即停；需要 App 关闭后仍必达的任务，指向系统级自动化（如 Apple Shortcuts）。iOS 会挂起后台进程，「已注册」不等于「会执行」。
- 工具结果固定替换或错配即停依赖操作；由可靠独立通道回读对象判定实际写入，状态未明不重试、不采信污染输出。`minis-model-use run` 按当前 `--help`、版本及请求链路核验，报错不单独定因；`minis-mcp-cli` 改配置或环境变量后须 `shutdown` 再 `ping`，否则守护进程沿用旧配置（表现为 401）。
