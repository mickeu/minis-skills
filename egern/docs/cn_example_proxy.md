# Egern 作为代理工具
Egern 可作为代理工具代理网络流量，以下列子说明了如何添加代理服务器和使用远程代理订阅。
## 使用代理服务器​
### 添加 Shadowsocks 代理服务器​
点击 `工具` -> `代理` -> `+`，填入`名称`，`服务器`，`端口`，`方法`和`密码`，点击保存。
### 添加代理服务器到策略组中​
点击 `策略组` -> `Proxy` -> `ss` -> `保存`。
## 使用远程代理的订阅地址​
### 修改 Proxy 为外部策略组​
点击 `策略组` -> `Proxy` -> `类型` -> `外部的` -> `添加新的 URL`，填入远程代理的 URL 地址，点击 `保存`。
