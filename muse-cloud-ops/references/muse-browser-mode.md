# Muse 浏览器驱动模式操作指南（B 模式）

## 用途

在 Muse **无官方公网入口**（实测见 `muse-sandbox-facts.md`）的情况下，不部署常驻 MCP、不做隧道/保活，改用 **Minis 内置浏览器打开 Muse 网页对话**，让 Muse 平台**按需唤醒真实 VM** 执行任务，再从对话回复中回收结果。完全走官方界面，零合规风险。

## 入口与登录

- Muse 网页入口以用户实际登录页为准（注册/登录入口：`https://muse.ai`）。
- Minis 内置浏览器首次需要用户**手动登录**；登录后会话保持，后续打开直接可用。
- 若登录态失效，提示用户重新登录，不要用自动化绕过登录/验证码。

## 浏览器操作流程

1. `browser_use` `navigate` 到 Muse 网页入口。
2. 确认页面出现对话输入框（已登录）。若未登录，让用户手动登录。
3. 在输入框 `type` 任务指令（用下面模板）。
4. 发送后等待 Muse 回复：轮询 `get_text` 或 `wait_for_dom_stable`，直到回复出现。
5. 从回复中提取：关键输出、文件路径、大小、校验值、任务 ID。

## 任务指令模板

### 通用任务模板

```text
请在这个云电脑里执行以下任务：

<任务描述>

要求：
1. 脚本写到 /home/hatch/pdata/scripts/，数据写到 /home/hatch/pdata/data/
2. 完成后把关键输出、文件路径和大小贴给我
3. 如果中途出错，说明出错步骤和原因
```

### 下载文件

```text
请下载这个文件：<URL>
保存到 /home/hatch/pdata/data/<文件名>
完成后告诉我文件大小和 sha256
```

### 批量 Python / 数据处理

```text
请用 Python 处理 <任务>。
脚本保存到 /home/hatch/pdata/scripts/xxx.py，结果保存到 /home/hatch/pdata/data/xxx
完成后贴出运行结果摘要
```

### 配置 Scheduled Task（定时任务）

```text
请配置一个官方 Scheduled Task：
- 任务名称：<name>
- 执行周期：<cron 表达式，如 每天 09:00>
- 执行内容：<命令或脚本路径>
- 审计日志：/home/hatch/pdata/data/<name>.log
完成后告诉我任务 ID 和状态
```

### 长任务完成后回收结果

```text
检查 /home/hatch/pdata/data/ 下最近的任务结果，贴出文件列表、大小和内容摘要
```

## 结果回收

- **文本结果**：直接从 Muse 回复中复制。
- **文件**：让 Muse 提供云端路径；如需下载到手机，请 Muse 使用平台自带下载/分享机制，或用 `download_file` 类官方能力。
- **长任务**：Muse 在云端执行，Minis 退出不影响执行；回来重新打开 Muse 网页，让 Muse「检查 pdata 下的结果」即可回收。

## 合规与注意事项

- 只用官方网页交互，**不**要求 Muse 部署反弹 Shell/隧道/常驻外联（Sentinel 审查封号）。
- 数据一律放 `/home/hatch/pdata/`（持久化），不放根目录（重启清空）。
- 对话上下文有长度限制：重要任务独立开新会话，避免上下文丢失导致误判。
- 不把浏览器自动化当作绕过审核/验证码的手段；遇到登录墙、人工验证就让用户手动处理。
