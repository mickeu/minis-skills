# Open Minis 更新日志

## 版本 1.15 Build 5 — 测试版

- **构建号**: 1.15 Build 5
- **来源**: 用户提供

### 新功能
- **分享对话为长图/PDF**：可将对话任意部分分享为长图或 PDF，支持逐条选择回复/工具调用/思考内容，可拖动选择、"选择下方全部"，可隐藏思考或工具调用；可选手机宽度、iPad 宽度或自适应表格宽度，外观跟随浅色/深色模式，预览支持双击缩放；导出顶部显示助手头像、模型和日期。入口在消息长按菜单的"分享对话…"
- **输入框显示额度与余额**：上下文用量提示行同时显示当前模型的剩余额度或余额，订阅类额度同时显示 5 小时和 7 天限额
- **会话搜索改进**：搜索结果显示命中行并高亮关键词，文件夹可展开查看命中结果（每次 20 条，可"显示更多"）
- **快捷指令保存环境变量到 Minis**：新增快捷指令动作，可将快捷指令中的文本保存为 Minis 可用的环境变量
- **语音输入校正改进**：语音转写会还原被音译的英文术语，并按不同语言应用各自的规则
- **新增模型**：Claude Sonnet 5.5
- **配置变更更易读**：通过命令行修改的配置，在审批页和"配置变更"中以通俗语句描述，并新增每条记录的详情页
- **移动到分组排序**："移动到分组"列表按最近活跃程度排序

### 问题修复
- 访客进程故障恢复时导致应用崩溃
- OAuth 登录被拒绝或失败后崩溃
- 同时打开多个对话时，浏览器、定时任务和模型调用命令作用到错误对话
- Claude 5 模型上"关闭思考"发送方式不正确
- 新对话在发送首条消息前设为关闭思考，发送后又恢复默认等级
- 展开的思考块在流式输出时不随文字增长高度
- iPad 上浮动或未停靠键盘顶起输入框并在下方留出空白
- 表格未按实际渲染宽度排版
- iPad 宽度下，图片说明下方的 Markdown 图片没有另起一行
- 使用 Windows 换行符的 SKILL.md 导入后名称显示为"Untitled Skill"
- 输入框占位文字换行后紧贴按钮行
- 助手把内置 apple-* / minis-* 命令当作工具而非 shell 命令

## 版本 1.15 Build 2 — 测试版

- **构建号**: 1.15 Build 2
- **来源**: 用户提供（TestFlight 截图）

### 新功能
- **AOJIT 体验版**：为内置 Shell 新增实验性预编译执行模式，加快常见命令、图像处理（Pillow）及网络/加密操作（SQLite、OpenSSL、PCRE2）运行速度。默认关闭，在 设置 → Rootfs Management → AOJIT 中开启。开启后可能需通过"修复"提示重新安装匹配版本的 Python/Node.js；不支持或版本不匹配的环境下表现可能与标准 Shell 不同
- **Always On 模式**：长时间任务运行时屏幕保持常亮并显示调暗的黑屏遮罩，不自动熄屏，方便随时查看进度。可在对话"…"菜单中开启（仅本次或设为默认），新增屏幕保护设置可调整多久后进入全黑
- **长按发送按钮设置回车键行为**：长按发送按钮弹出菜单，可直接选择回车键的行为

### 问题修复
- 快捷指令后台运行的会话不会生成标题
- Anthropic 请求在仍有数据到达时被 60 秒超时打断
- 恢复备份时无法找回本设备上已删除的模型分组
- 恢复备份后思考等级被提升或丢弃、而非按原设置还原
- 模型被过度引导使用某个特定搜索工具，可能挤占其他合理方式

## 版本 1.14 Build 21 — 测试版

- **构建号**: 1.14 Build 21
- **来源**: 用户提供（更新日志）

### 新功能
- **上下文用量提示**：输入框实时显示当前对话占用模型上下文窗口的比例；用量跨过 70% / 80% 时输入框边缘出现渐亮提示光效；语音面板状态栏同步显示。

### 问题修复
- MCP 环境变量行处于编辑状态时删除该行不再崩溃
- 模型 ID 含点号时，模型配置路径出错
- Anthropic 模型工具结果图片有时被附加到错误请求上
- 网络/传输失败被误判为需要强制压缩上下文
- 列表标识重复导致侧边栏崩溃
- 恢复备份的技能文件需重启 App 才生效
- 启动时聊天存储一次性初始化导致卡死
- deepseek-flash 模型未被正确识别为原生思考模式
- 长上下文人格提醒不再破坏 prompt 缓存，也不再伪装成工具输出出现

### 性能优化
- 会话列表和消息列表性能优化，减少大量聊天记录下的启动耗时和滚动卡顿
- 内置 Linux 终端 timeout 命令超时后能真正杀掉命令
- 内置 Linux 终端可正常启动 Tailscale 等需读取系统网络路由表的网络工具
- 内置 Linux 终端同时运行大量进程时，更不容易把设备烤热、拖慢或卡死

## 版本 1.14 Build 15 之前（汇总）

### 新功能
- gpt-image-2.5 图像模型（Codex OAuth）
- **子代理委派（Sub Agents）**：Agent 可将子任务委派给独立运行的子代理，支持排队、中途纠偏、中断后恢复
- Agent 工具拆分为两个开关（Browser Use、Agents）；定时任务归属对话，显示下次触发时间并支持对话内取消
- 新增 xAI 极速模式开关

### 问题修复 / 优化
- 子代理体验打磨：推理等级以徽标显示在模型旁，可随同步/备份保留；委派队列容量提升；控制调用卡片渲染更一致
- 修复两个 1.14 (11) 崩溃、图片请求预算、Gemini 思维签名拆分、超长对话人格丢失，以及一批聊天/备份/引导页小问题
- 修复标题生成、超长粘贴、快捷指令提醒/日历列表匹配问题
- 修复粘贴文本显示/发送不一致、跨会话资源解析错误、长对话冷启动卡死、语音输入错误提示问题
- 修复超大工具结果崩溃、终端 DNS 卡死、重启后空白界面问题
