## 版本 1.15 Build 13 — 测试版（iOS）

- **构建号**: 1.15 Build 13
- **来源**: 用户提供（TestFlight 更新日志）

### 新功能
- **长对话上下文优化**：超出安全水位时先裁剪旧推理和大输出，再决定是否压缩；上下文估算更准，长对话更不易提示已满
- **停止前确认**：停止运行中的任务前先确认，可在设置「停止前确认」关闭，默认开启
- **任务通知更准确**：没跑完的任务不再通知为「已完成」；后台时间用尽、上下文已满或出错，会分别通知为暂停或失败

### 优化
- 向用户提问：问题被截断时才显示「显示更多」，且点击区域更大
- 向用户提问：未回答的延后问题一小时后自动关闭，每个问题只发一次通知
- 向用户提问：问题缺少类型但能从字段推断时，不再被拒收
- 语音按钮「转写中」弧线贴合在白色按钮内侧，两端有淡出效果
- 读取图片失败时显示具体原因，同一批工具调用中的读取会等待前面的写入

### 问题修复
- 修复压缩时单轮超过 100 条消息会丢失用户请求，以及提醒被当作用户轮次的问题
- 修复上下文窗口变化后仍按旧裁剪计划处理的问题
- 修复长对话中反复重新规划、总在压缩线附近徘徊的问题
- 修复输入框文本被程序替换后撤销导致崩溃的问题
- 修复后台定位会话被重复注销导致崩溃的问题
- 修复 OpenCode Go 的快速测试、压缩、语音校正、图像生成等入口因缺少会话头报 400 的问题
- 修复 OAuth 标记「需重新登录」后反复刷新、导致设置中供应商页面卡顿的问题
- 修复浏览器 JavaScript 错误只显示笼统提示、页面没有内容时直接报错的问题
- 修复回复以文字开头时对话向下跳动约 0.3 秒的问题
- 修复 Claude 登录令牌请求内容被写入应用日志的问题
- 修复 iSH 对无 inode 文件描述符加记录锁时崩溃、不支持 SHA512 指令的设备上 JIT 出错的问题

## 版本 1.15-beta.3 Build 32 — Android 测试版（GitHub Release）

- **构建号**: 1.15-beta.3 (build 32)
- **发布日期**: 2026-09-29
- **来源**: GitHub Release（tag `0-beta-build32`，官方中英双语更新日志）

### 新功能
- **长任务上下文管理**：在需要摘要压缩前，先从最旧开始逐步清理旧思考、卸载大的工具输出、合并旧步骤，长任务不再频繁压缩或超出窗口
- **停止确认**：点停止按钮先确认「停止这个任务？」，可在 设置 > 外观 > 停止前确认 关闭
- **子代理卡片**：显示任务、工具调用和最新输出，可引导（Steer）或停止；子代理完成时通知主对话
- **并发上限提升**：最多同时运行 6 个对话，每个对话最多 3 个子代理
- **定时任务**：长按计时胶囊菜单可「立即执行」
- **会话内 MCP 面板**：支持搜索、全部启用/停用、服务器详情页；技能面板可查看详情，长按可复制 URL 技能的来源地址
- **长按工具状态栏**：开关预览窗口；长按思考块开关「流式输出时展开思考」
- **朗读音量滑块**：朗读时压低其他应用的声音
- **清理孤立会话文件**：设置 > 存储 新增
- **Per-provider 响应超时**：OpenAI 兼容服务商可单独设置响应等待时间（适合本地模型）
- **Kimi Code 订阅用量**：MiniMax 和 OpenCode 直接链接官方控制台

### 问题修复
- DeepSeek：工具调用误写进思考会自动重试；后期空回复先重试再提供「继续」；输出上限截断时明确提示并提供「继续」
- 中转模型（如 code-buddy/deepseek-v4.1-flash）识别真实上下文窗口、输出上限和思考档位，不再被猜成 128K
- OpenCode Go：Quick Test、图片识别、语音纠错、文件夹建议、生图和 minis-model-use 请求正常
- 刷新模型列表显示结果或失败原因；Codex 请求恢复账号 ID 并复用提示缓存
- 任务中途删除/停用服务商后自动切换组内下一个模型
- 工具结果始终紧跟调用（压缩后也正确，修复 Anthropic/Gemini 报错）
- shell 输出中文等多字节字符不再乱码，沙盒 git 恢复可用
- 发送前缩小的图片不再丢失；浏览器 UA 设置对新标签生效；Cookie 清除/逐站删除恢复
- 语音录音中点发送只发一次；记忆/人设/技能编辑器键盘不再挡编辑行
- 对话标题跟随重命名；复制对话标题区分「(Copy)」「(Copy 2)」
- SMB 凭据显示、恢复进度本地化；悬浮胶囊位置保留；启动崩溃自动恢复；用量多币种显示修复

### 视觉打磨
- 子代理统计小标签紧凑统一；菜单阴影完整且与屏幕边缘保持间距；提示对齐、分隔线、加载动画圆环

- 工具胶囊停止状态修复；模型回退红色闪烁不再卡住；STDIO MCP 服务器数量有上限且停止时结束整个进程树

### 视觉打磨
- 提问卡片更紧凑；折叠工具行与回复文字左对齐；最后一条消息与浮动工具栏间距一致
