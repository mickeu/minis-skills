让任意具备浏览器能力的 AI Agent，在你的**本人京东账号**上完成大促红包领取、神券抢夺和整点活动参与。

实测战绩（2026.10.20-10.27，逐条可对 [references 战例](references/double11-2026.md)）：¥30 惊喜红包、整点猜锦鲤第一局即中（¥3 东券 + 白条 6 期免息）、晚 8 点踩点三连（¥1.18 现金 / ¥2 东券 / ¥1.18 现金）、猜数字二分法命中（¥0.68 无门槛现金）、猜拳一局定胜（¥0.68 无门槛现金）、安慰奖（¥0.27）。每日两场整点布防。

所有战绩均来自真实账号实抢，战术规则来自双宿主对照实验 + 实战持续迭代。

## 它能做什么

- 🧧 主会场红包「抢」按钮、大额补贴券、惊喜膨胀券、PLUS 专享券
- ⏰ 整点限时活动（猜拳 / 猜大小 / 猜锦鲤数字等轮变玩法，按页面实际显示执行）
- 🎟️ 日常红包口令：京东 App 搜索「**福利天天领600**」，双11 期间每天 3 次（仅 App 内有效，PC 搜索为零结果）
- 📈 实战战术内置：两种场次（直塞/游戏）按横幅自动判别，标准时间表执行（T-6 进场体检 → 整点前 1-2 秒踩点刷新 → 整点后点抢）；失败后不刷新同容器续打；战果只见到账弹层，不认历史权益提醒
- 🤖 可选无人值守：定时唤起常驻 Agent 到点自动抢（用户明确授权后接入）
- 🛡️ 边界清晰：登录/验证码永远交给本人，不碰 Cookie，不做多账户，不进下单流程

## 3 分钟上手

1. **安装**：把本目录整体拷入你 AI 工具的 skills 目录（见下表），重启或刷新会话；
2. **浏览器**：工具已有浏览器能力（内置或已配 MCP）→ 跳过；没有 → 对 Agent 说"帮我配置浏览器工具"，它会按 [references/windows-browser.md](references/windows-browser.md) 引导你；
3. **开抢**：对 Agent 说一句
   > 使用 jidonghongbao，帮我看看双11有什么红包能领

   首次会走"只看不点"验收，登录交给你，领取前会向你确认。
