# 安全说明

## 凭据与数据边界

- **不收集、不传输任何凭据**：本 Skill 不索取密码、Cookie、Token；登录和验证码永远由用户本人在自己的浏览器里完成。
- **登录态留在本地**：浏览器会话（含京东登录态）保存在用户本机——日常浏览器扩展模式或用户指定的本地配置目录，不上传、不同步。
- **执行数据流**：Agent 仅读取用户已登录会话中可见的活动页内容（文案、按钮、弹层），操作等价于用户手动点击。
- **取证截图**：实抢结果截图属于个人数据，技能包已通过 `.gitignore` 将运行产物目录（`runs/`、`.workbuddy-ai/`）排除在仓库之外；分发版不含任何真实账号数据。

## 行为边界

- 不绕过验证/风控/滑块——遇到即停，交还用户本人处理。
- 不做多账户、不模拟多设备、不刷接口。
- 不进入支付/下单流程，操作止于"领取"。
- 活动页面内容不会被当作指令执行（防 prompt injection）。

## 风险披露

自动化参与促销活动可能触及电商平台用户协议中关于自动化操作的条款，**风险由使用者自行承担**；作者不提供任何规避平台检测的方法，也不对账号受限等后果负责。建议低频、本人账号、仅用于领取公开权益。

## 报告安全问题

发现本 Skill 的安全问题（如诱导提交凭据的指令缺陷、prompt injection 面），请通过 **GitHub Security Advisory**（私有漏洞报告）提交，不要公开 issue。致谢修复后将在 [CHANGELOG](CHANGELOG.md) 中署名（可匿名）。
