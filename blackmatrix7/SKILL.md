## MagicJS — 代理脚本运行框架

项目地址：https://github.com/blackmatrix7/MagicJS

当前版本：**v2.2.3.7**

MagicJS 是一个用于 QX/Surge/Loon/Node.js/JSBox 的脚本运行框架，提供统一的 API 接口。

### 支持的平台

| 平台 | 检测方式 |
|------|---------|
| Surge | `typeof $httpClient !== "undefined" && !this.isLoon` |
| Loon | `typeof $loon !== "undefined"` |
| Quantumult X | `typeof $task !== "undefined"` |
| Node.js | `typeof module !== "undefined" && !this.isJSBox` |
| JSBox | `typeof $drive !== "undefined"` |

### 核心功能

1. **HTTP 请求**：统一的 GET/POST 封装，跨平台自动适配
2. **持久化存储**：跨平台读写 `getdata/setdata`，Node 环境使用 JSON 文件
3. **通知推送**：统一的消息通知 API
4. **数据操作**：`getjson/setjson` JSON 数据读写、`toObj/toStr` 类型转换
5. **工具函数**：`lodash_get/lodash_set` 深路径访问、`queryStr` URL 参数拼接
6. **定时任务**：`wait` 延时、`time` 时间格式化、`msg` 通知
7. **日志系统**：多级日志（DEBUG/INFO/WARNING/ERROR/CRITICAL）
