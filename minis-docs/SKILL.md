# Minis (Open Minis) 完整官方知识库

## 总览

Minis（Open Minis）是一款超越对话框的设备端 AI 智能体。它能自主行动——浏览网页、读取健康数据、管理日程、控制智能家居、自动化复杂任务。一切都在设备上私密完成。

支持平台：iOS 16+ / iPadOS 16+ / macOS 13+ (Apple Silicon) / visionOS 1.0+ / Android 10+（预览版）

### 核心功能
- **多模型 AI 接入**：Anthropic Claude、OpenAI GPT、Google Gemini、OpenRouter 或任意 OpenAI 兼容接口
- **内置 Linux Shell**：完整的 Alpine Linux 环境，可编写脚本、安装软件包、处理数据
- **深度系统集成**：日历、通讯录、定位、照片、剪贴板、天气、通知等；iOS 额外支持 HealthKit、HomeKit、提醒事项、蓝牙、NFC
- **内置浏览器**：浏览网页、填写表单、提取内容、截图
- **自定义技能**：导入或创建 SKILL.md 格式的技能扩展
- **MCP 集成**：通过模型上下文协议连接任意第三方服务器，支持 HTTP 和 STDIO 传输方式
- **隐私优先**：API 密钥存储在设备 Keychain，不收集数据

## 一、快速开始

### 1. 下载安装
从 App Store 下载，或下载安卓 APK（Android 10+，预览版）。

### 2. 添加 AI 提供商
首次启动时系统引导添加 AI 提供商。选择支持的服务商并输入 API 密钥。

创建新会话开始聊天。智能体可执行命令、浏览网页、读取日历等。

## 三、高级配置

### 模型组（Model Groups）
将多个模型组合，配置路由策略：
- **故障转移**：按顺序尝试，失败则自动切换下一个
- **负载均衡**：将对话均匀分配到各模型

### 智能体循环模型（Agent Loop）
配置独立模型池，供 AI 智能体在委派子任务或推理复杂操作时使用。

### 增强缓存（Prompt Caching）
仅适用于 Anthropic Claude 模型。开启后激活 1 小时提示词缓存，缓存的 Token 费用仅为标准价的 1/10。适合长时间多轮复杂任务。首次请求费用为标准价的 2 倍（创建缓存）。

## 四、会话文件系统

每个会话拥有独立文件系统，挂载在 `/var/minis/` 下：

| 目录 | 用途 | 隔离性 |
|------|------|--------|
| minis://workspace/ | 工作文件、脚本、数据 | 会话独立 |
| minis://attachments/ | 图片、音频、视频 | 会话独立 |
| minis://browser/ | 浏览器截图和提取内容 | 会话独立 |
| minis://offloads/ | 大型工具输出 | 会话独立 |
| minis://memory/ | 记忆 | 所有会话共享 |
| minis://skills/ | 技能 | 全局共享 |
| minis://shared/ | 跨会话共享 | 全局共享 |

> 注意：「清除聊天」会同时删除该会话的工作区文件。清除前请将重要文件复制到 Memory 或 Skills 目录。

## 六、安卓专属能力

### 无障碍自动化
通过内置无障碍服务，读取任意 App 的 UI 树、点击按钮、填写表单、滚动、检测对话框、全局截图、监听实时 UI 事件。

### Shizuku 特权操作
通过 Shizuku（或 AXManager）获得 adb 级别权限：安装/卸载应用、授予/撤销权限、管理应用权限、控制显示设置、读写系统设置、执行 Shell 命令。

### 定时任务
内置 AlarmManager 驱动的任务调度器。创建单次或重复的 AI 任务（每天、工作日、自定义周期），可运行新提示词、追加到已有会话或重跑历史对话。

### 悬浮窗状态
智能体在后台运行时，可拖拽的悬浮胶囊实时显示当前工具名称和执行状态。

## 七、FAQ 完整解答

### API 配置与网络

**Q: 为什么我的 API 密钥显示「无效」或认证失败？**
- Google Gemini OAuth 有严格的第三方限制，建议改用 API Key
- 检查账户余额，确认有足够额度或在免费配额内
- 网络稳定性：智能体模式需要稳定连接。如使用代理或 VPN，请为 Open Minis 分配固定节点

**Q: 如何添加 OpenAI 兼容提供商（如 Qwen、DeepSeek）？**
选择「自定义（OpenAI 兼容）」，输入基础 URL（不含末尾的 /v1/... 路径）和 API 密钥。若模型列表未自动加载，手动输入模型 ID 即可。

**Q: 如何配置第三方 API 代理/中转？**
确认是 OpenAI 兼容还是 Anthropic 兼容。仅输入基础 URL（去掉末尾路径）和 API 密钥。若模型未自动出现，手动输入模型 ID。

### 模型选择与使用

**Q: 哪个模型最适合智能体任务？**
| 场景 | 推荐 |
|------|------|
| 通用智能体任务 | Claude Sonnet / Opus |
| 长对话稳定性 | GPT-4o / GPT-5 |
| 经济实惠 | Kimi、MiniMax、Qwen |

**Q: 什么是「增强缓存」，什么时候应该开启？**
仅适用于 Anthropic Claude 模型。开启后激活 1 小时提示词缓存，缓存 Token 费用为标准价的 1/10。适合长时间多轮复杂任务。首次请求费用为标准价的 2 倍。

**Q: 为什么模型长时间停在「思考中」？**
部分模型（如 DeepSeek R1）具有扩展推理模式，耗时较长。如需更快响应，切换为 Claude Sonnet 或 GPT-4o 等非推理模型。

### 技能

**Q: 如何安装新技能？**
1. **浏览安装**：进入设置，浏览官方技能库
2. **发送链接**：将 SKILL.md 的 GitHub URL 粘贴到对话中，智能体会自动安装
3. **让智能体创建**：用自然语言描述需求，功能强大的模型（如 Claude）可为你编写并安装技能

**Q: 安装的技能缺少脚本文件？**
通过 GitHub URL 安装目前仅下载 SKILL.md 文件。若技能依赖额外脚本，请让智能体下载完整仓库或根据 SKILL.md 重新生成脚本。

**Q: 刚创建的技能没有出现在设置中？**
对话中创建的技能可能不会立即显示。离开设置页再重新进入即可刷新。

### 文件与存储

**Q: 如何将文件导入会话？**
- iOS：由于沙盒限制，可将文件内容粘贴到对话中，或先上传到 iCloud Drive，再让智能体从 iCloud 路径读取
- Android：直接使用附件按钮从设备存储中选取文件

### 终端与 Linux 环境

**Q: 内置终端支持哪些语言和工具？**
- Python：完全支持，推荐用 uv 管理依赖
- Node.js：部分支持
- Go / Rust：支持
- FFmpeg：内置，支持硬件加速

**Q: 安装的软件包会在会话间持久化吗？**
是的。通过 apk 或 pip 安装的软件包会持久保留在 Alpine Linux 文件系统中，除非执行「重置根文件系统」。

**Q: tar 命令卡住 / GitHub CLI (gh) 崩溃？**
- tar 卡住：运行 `apk add tar` 安装独立版本
- gh CLI：使用 `GITHUB_TOKEN` 环境变量通过 GitHub API 代替

### 自动化与后台任务

**Q: 如何让智能体在后台持续运行？**
在设置中开启「后台音频保活」，通过播放静音音频防止系统挂起应用，任务完成后自动停止。

**Q: 能设置定时/自动化任务吗？**
- iOS：通过 iOS 快捷指令实现。Open Minis 提供快捷指令动作
- Android：使用内置的定时任务功能，支持单次、每天、工作日和自定义重复计划

### 其他

**Q: 长对话变慢了怎么办？**
上下文超过约 8 万 Token（尤其含图片或大文件时），渲染可能卡顿。让智能体将对话摘要存入记忆文件，再开启新会话继续。

**Q: 在哪里查看通过智能体创建的闹钟？**
点击 Open Minis 主页的闹钟图标，或让智能体列出闹钟。这些闹钟不会出现在 iOS 系统时钟 App 中。

**Q: 智能体能打开其他 App 吗？**
- iOS：可以通过 URL Scheme 打开支持该方式的 App（如地图、设置、Safari），但无法控制其他 App 的界面
- Android：支持通过 Intent URL Scheme 启动对应的 App

## 八、Minis 技能生态系统

### 技能是什么？
技能是包含 SKILL.md 文件的目录，通过三级加载系统工作：
1. **元数据**（Frontmatter 中的 name + description）—— 始终在上下文中，用于触发
2. **SKILL.md 正文** —— 触发时加载到上下文（建议 500 行以内）
3. **捆绑资源** —— 按需加载（脚本、参考资料、资源文件）

### 技能目录结构
```
skill-name/
├── SKILL.md              # 必需 — 元数据 + 指令
├── evals/                
│   └── evals.json        # 可选 — 测试用例
├── scripts/              # 可选 — 可执行脚本
├── references/           # 可选 — 参考资料
└── assets/               # 可选 — 模板、图标、字体
```

### 技能创建指南
1. 目录名使用 lowercase-kebab-case
2. SKILL.md 必须包含 YAML frontmatter（name + description）
3. description 描述技能功能及触发条件
4. 正文使用祈使句，解释"为什么"而非只说"必须"
5. 超过 500 行时拆分到 references/
6. 不要硬编码密钥、密码
7. 可使用 skill-creator 技能辅助创建

## 八、版本更新日志

### v1.14 Build 11（App Store 最新）
**发布日期**：2026-09-02
**更新说明**

**修复**
- 自动生成对话标题时，有时会直接放弃、退回使用原始提示词文本，而没有真正重试其他候选模型；同一分组内的其他服务商也可能被跳过顺序有误——现在会正确重试，并按正确顺序遍历候选模型
- 手动为未归档的对话重新生成标题时，现在也会给出文件夹建议
- 粘贴超过 15000 字符的内容后，输入框里除了生成的文件卡片，还会残留一份原始文本——现在不再残留
- 通过快捷指令/自动化创建或编辑提醒事项/日历事件时，有时会误报成功写入了错误的列表，或者静默失败却显示成功——写入操作现在会精确匹配目标列表/日历，并如实报告失败；每次写入成功后也会返回该列表/日历的唯一标识，修改提醒事项到期时间时其内部起始时间也会保持同步

**上一版本（更早发布）**

**修复**
- 粘贴的文本有时在刚发送的消息里显示不正确，或与模型实际收到的内容不一致——粘贴内容现在只在构建请求时展开一次，且 `[Pasted#N]` 卡片会在消息发出的瞬间就正确显示（不必等重新加载）
- 另一个会话在后台加载时，文件/图片预览和链接偶尔会跳转到错误对话
- 打开很长的对话时，因为所有消息都在主线程渲染而导致界面卡死——冷启动加载改为渐进式，长会话历史可以顺畅打开
- 长按一条很长的回复时，构建预览可能导致界面卡住——预览内容现在有长度上限
- 麦克风被其他 App 或系统功能占用时，语音输入有时会报"解析失败"——现在会正确显示真实原因；同时修复了语音检测启动失败时音频会话未正确回滚的问题

**更早版本**

**修复**
- 打开超大工具调用结果（如 50KB+ 的子代理审查记录）时白屏卡死甚至闪退——长内容现在会分批加载
- 终端里 nslookup/dig 卡死不退出，以及设备重启后启动 App 出现空白界面
- 新增：xAI（Grok）服务商设置新增"极速模式"开关

### v1.12 Build 16（App Store，当前最新）
**发布日期**：2026-08-12
**大小**：92.4 MB

**App Store 更新说明**

- 全新的 Markdown 预览体验，让每一步操作都清晰可见
- 丰富的技能与自定义能力，让 Minis 成为你的专属助手
- 智能对话，支持多种 AI 模型，自由选择最适合的模型

**详细变更（从 v1.12 Build 10 TestFlight 累积）**

**新功能 / 改进**

1. **自定义 Thinking 规则** — Provider 详情页新增"Thinking Rules"区域，可以按模型新增、编辑、删除、排序推理参数的发送规则。规则支持 iCloud 同步，也可通过 `minis-config` 脚本化管理。

2. **Vision Group：让不支持视觉的模型也能"看图"** — 不支持原生视觉模型（如 DeepSeek V3/R1 等）现在也能理解图片：Minis 会先调用一个支持视觉的模型描述图片内容，并告知是哪个模型完成的识别，失败时也会明确提示。

3. **全局 Liquid Glass 玻璃特效** — iOS 26 上，首页悬浮按钮、消息输入框、工具调用状态栏以及发送的消息气泡都改用 Liquid Glass 玻璃材质，背后内容会透过玻璃产生折射效果，边缘也比之前手绘的阴影和描边更干净。旧版本 iOS 外观不受影响。

4. **修复提示词缓存相关问题** — 修复了几个导致提示词缓存无法生效的问题：通过 OpenRouter 调用 Claude 模型现在能正确使用缓存。

**提醒增强** — 新增了"移动到分组"的操作入口，展开分组浏览时顶部会有导航条方便跳回分组标题。

**丰富了 Apple 工具的参数与数据**
- `apple-reminders` 新增地理围栏提醒，支持"到达/离开某个地点时触发"，可指定地点名称、经纬度和触发范围；同时支持设置重复提醒（每日/每周/每月等循环规则）
- `apple-notification` 新增通知重复发送，以及为通知附加交互按钮（如"确认"/"稍后"等）
- `apple-weather` 新增 `minute` 子命令，返回未来一小时内逐分钟的降水强度数据，适合需要精确判断"接下来几分钟会不会下雨"的场景

**修复**

**修复后台运行被系统强杀的问题** — 在后台使用 shell 工具时，进程有时会被系统强制终止。这次修复后，后台任务不再被系统杀掉，运行效率也更高。

**问题修复**
- 撤销了此前给会话存储目录自动生成 README.txt 说明文件的做法
